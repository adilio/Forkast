# Forkast

Forkast is a household recipe manager and store-aware shopping PWA.

The initial product scope is:

- Import recipes from Plan to Eat.
- Save clean recipes from websites on iPhone.
- Star favorite recipes.
- Scale ingredient quantities by serving size.
- Maintain synchronized City Market and Costco shopping lists.

Implementation planning is in progress. The application will use React, Vite,
Netlify, and Firebase.
